# AI Document Analyzer

## Project Stack
- Frontend: React
- Backend: Node.js + Express
- Version Control: Git & GitHub

## Coding Conventions
- Use meaningful variable names.
- Write clean, modular code.
- Comment complex logic only.
- Follow consistent formatting.
- Keep components reusable.

## AI Assistant Instructions
- Explain code before generating it.
- Suggest best practices.
- Help debug errors.
- Keep solutions simple and maintainable.

## Project Rules

1. Build new UI features as reusable React components instead of placing everything in a single file.
2. Disable action buttons until all required user input is valid.
3. Review AI-generated code for accessibility, edge cases, and usability before merging.
4. Validate uploaded files before enabling document analysis.
5. Separate component logic from styling by keeping CSS in dedicated files.
