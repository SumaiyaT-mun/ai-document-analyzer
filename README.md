# ai Document Analyzer

## Overview
AI Document Analyzer is a web application that helps users upload documents and use AI to generate summaries, extract key points, and answer questions about the content.

## Features
- Upload PDF, DOCX, or TXT files
- AI-powered summaries
- Key point extraction
- Question answering

## Getting Started

### Prerequisites
- Node.js (LTS)
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/ai-document-analyzer.git
   ```

2. Navigate to the project folder:
   ```bash
   cd ai-document-analyzer
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   npm start
   ```
