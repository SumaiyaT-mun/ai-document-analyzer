# AI Document Analyzer

## Overview
AI Document Analyzer is a web application that helps users upload documents and use AI to generate summaries, extract key points, and answer questions about the content.

## Features
- Upload PDF, DOCX, or TXT files
- AI-powered summaries
- Key point extraction
- Question answering

## Tech Stack
- React
- Node.js
- Express
- Git & GitHub
